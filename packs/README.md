# Ресурс-паки для иконок предметов

Положи сюда zip-архивы паков (как скачал, распаковывать не нужно). Сайт берёт текстуру предмета
из первого пака, где она есть, в таком порядке:

1. **Hypixel Plus** (ic22487)
2. **FurfSky Reborn** (FurSky Team)
3. **Hypixel SkyBlock** (официальный пак Hypixel)

Потом идут готовые иконки из `db/icons` и Coflnet. Порядок можно поменять файлом `order.json`, например:
`["furfsky", "hypixel plus", "hypixel skyblock"]` (сравнивается часть имени файла, без учёта регистра).

Паки в репозиторий не попадают: их лицензии не разрешают распространение, каждый скачивает их сам
с официальных страниц авторов.

**Кто видит текстуры паков.** Hypixel Plus распространяется по CC BY-NC-ND 4.0 (только некоммерческое использование),
у FurfSky Reborn все права защищены. Пока на сайте нет рекламы, текстуры видят все (авторы указаны на /legal).
Как только в `.env` появляется блок РСЯ (`YANDEX_RTB_BOTTOM` или `YANDEX_RTB_LANDING`), текстуры паков автоматически
остаются только владельцу, остальные видят головы из скинов и ванильные текстуры. Вручную: `PACKS_PUBLIC=all`, `none`
или список паков, на которые есть письменное разрешение автора (например, `PACKS_PUBLIC=furfsky`).
Связь с авторами: FurfSky — Discord discord.gg/fsr, Hypixel Plus (ic22487) — Discord с его страницы на Modrinth. После добавления паков перезапусти сайт или открой `POST /api/packs/reload`.
